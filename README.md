A program that writes one line to entry.txt — the line a stranger meets mid-scroll: "You just scrolled past your ex, a man marrying a pizza, and three ads for socks you already own. Stop here — this line is the only thing today that isn't selling you something."

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/output python3 main.py
```
